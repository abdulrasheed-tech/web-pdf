# Web PDF — by Lit By Bit

Free, private PDF editor in your browser. Merge, reorder, delete and rotate PDF pages.

- No account, no upload — files are processed locally in your browser
- Built with pdf.js (preview) and pdf-lib (merge/download)
- Static site — deploy anywhere, including Vercel

## Use it

Open `index.html`, drop in one or more PDFs, reorder / rotate / delete pages, then click **Download merged PDF**.
